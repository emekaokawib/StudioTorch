# StudioTorch

StudioTorch implements a data-driven, cloud-based real-time framework for automated-deployment pipelines and continuous testing suite generator.

StudioTorch is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/StudioTorch.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure StudioTorch, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
